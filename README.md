## Description

My **call_me_maybe** project takes input prompts from the `data/input/function_calling_tests.json` and searches with the support of the `data/input/functions_definition.json`, the predefined function defintions, a function that matches the prompts meaning.

Then it transform the prompt data into an JSON output, that includes the Prompt, the name of the assigned function and the Parameters which are extracted from the prompt. That all works with an LLM that is provided within the Project and reads out the Prompt token by token.
